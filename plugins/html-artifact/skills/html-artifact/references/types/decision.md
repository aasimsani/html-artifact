# Decision memo, comparison of options

Lead with the recommendation, then show why it survives the alternatives.

## Spine

1. **Masthead.** The `h1` is the recommendation ("Use Unleash for feature flags"). The lede names what it costs.
2. **Recommendation.** A callout with the decision and the one reason that settles it.
3. **Comparison.** A table with options as rows and criteria as columns, plus a verdict column. Mark hard requirements pass or fail, and say a failed hard requirement disqualifies the option. Give each score a short reason in the cell or a footnote.
4. **What would change the answer.** Two or three sentences on which assumption, if wrong, flips the recommendation.
5. **What we commit to.** A numbered list of next steps, each with an owner.

## Avoid

- Scores with no reasons.
- Hiding that the winner fails a hard requirement.
- Walking through options one paragraph each.
