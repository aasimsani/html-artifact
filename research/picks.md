These were made in `research/proposal_html-artifact-v2.html` and pasted back by the user. Afterwards, the user widened scope to "a general reviewable document tool which allows for iteration and interaction, with reusable components". That moved all seven f-labs artifact types to Build now, slide deck included. The four router features came from the user's own request, so they are Build now as well.

- Tables, lists and checklists: clean table style, sortable/filterable tables, ranked checklist, phased plan checklist, numbered steps, test-plan checklist, cause chain, weighted comparison matrix, chart form chooser
- Writing: conciseness rules, lists over paragraphs, per-type skeletons, sources + redaction

- Review loop: annotation side panel, delete / replace / global, quick labels, decision blocks, Send to Claude, plan version diff, share links
- Interactive types: data explorer, ERD explorer, mind map, brainstorm grid, slide deck, playground / tuner, throwaway editor
- Plumbing: slim SKILL.md + type references, trigger evals, bench re-run
